# البرنامج المحاسبي ودفتر اليومية المطور (Smart Daily Journal & Accounting System)

برنامج محاسبي حديث متكامل مصمم خصيصاً ليحل محل دفاتر اليومية الورقية وملفات الإكسل، مع واجهة عصرية سريعة، حسابات فورية ذكية، وحفظ تلقائي في قاعدة بيانات محلية SQLite.

---

## 📋 الأقسام والميزات الرئيسية

### 1. بطاقات المؤشرات اللحظية (Live KPIs):
- **إجمالي المبيعات:** مجموع القنوات (نقدي، فيزا، توصيل، بنك، كليك).
- **المصاريف:** المصاريف التشغيلية والداخلية.
- **سحوبات الموظفين:** إجمالي مسحوبات وسلف الموظفين.
- **دفعات الموردين:** إجمالي سداد فواتير الموردين.
- **مشتريات نقدية:** إجمالي المشتريات النقدية للبضاعة.
- **مبيعات العطور:** مبيعات قسم العطور (دائن ومدين).
- **صافي القيمة المتبقية في الصندوق:** (مجموع المبيعات النقدية + مبيعات التوصيل) - (مجموع المصاريف + مسحوبات الموظفين + دفعات الموردين + المشتريات النقدية + دائن مبيعات العطور).
- **لغايات الايداع البنكي:** الحساب الشخصي وحساب المؤسسة.

### 2. قنوات المبيعات والإيداعات:
- مبيعات نقدية، توصيل، فيزا، الاتحاد، الاتحاد QR، كليك (CliQ).
- عداد القطع المباعة.
- تسوية الإيداعات في الحسابات البنكية وحساب الفرق المتبقي فوراً.

### 3. جداول المعاملات السريعة:
- **مصاريف داخلية:** تسجيل المصاريف اليومية المتنوعة.
- **سحوبات موظفين:** متابعة السلفيات وسحوبات الرواتب.
- **دفعات موردين:** تسجيل سداد فواتير الموردين.
- **مشتريات نقدية:** مشتريات نقدية سريعة.
- **الالتزام اليومي:** تسجيل القيود المدينة والدائنة ومطابقتها.
- **مبيعات عطور نقدي:** قسم خاص للمبيعات الفرعية.

### 4. جدول إخراج البضاعة والتحويل للتجار (الموديلات والمخزون):
- رقم الموديل، الصنف، الماركة، الكمية، اسم التاجر، السعر، والإجمالي التلقائي (`الكمية × السعر`).

### 5. الإيرادات الإضافية ومصروفاتها:
- فرق التوصيل، تصريف العملات، ومصروفات الإيرادات.

### 6. ميزات متقدمة:
- **حفظ تلقائي (Auto-Save):** يحفظ كل حركة تدخلها فورياً دون الحاجة للقلق من ضياع البيانات.
- **أرشفة وسجل كامل:** تصفح اليوميات السابقة باليوم والتاريخ.
- **طباعة رسمية بنقرة واحدة:** تنسيق جاهز للطباعة على ورق A4 أو الحفظ كـ PDF.
- **مدمج مع النظام المالي:** شجرة حسابات وميزان مراجعة وتقارير محاسبية.
